# API
## Последовательность действий
1. Создаёшь в Postgres БД managers
2. Делаешь пароль 1111
3. Запускаешь orm_models.py
4. Запускаешь data_filling.py (Для заполнения какими то данными (Все претензии к GPT))
5. Запускаешь сервер
6. Тестишь запросы через Postman
## Запуск сервера
**Из директории с api.py:**  
`uvicorn api:app --reload`
## Автоматическая документация к API
`127.0.0.1:8000/docs`
## Важные моменты
- Срок действия токена — 30 минут
- Для проверки работы api хорошее решение - postman
- Сначала надо зарегистрировать менеджера через api/register и только потом создать запросы с токеном, полученным при регистрации
- Когда регистрируешь запросы, они не прикрепляются к тому менеджеру, который их регистрирует, потому что по схеме БД распределение задач на менеджеров происходило по районам(areas). Это значит, что на менеджера записываются только те запросы, которые находятся в его районе.
- Запросы и их количество можно смотреть только для того менеджера, с чьего аккаунта зашёл
